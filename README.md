# 🎂 Age Calculator

A simple and interactive Age Calculator built using HTML, CSS, and JavaScript.
This project allows users to calculate their exact age in years, months, and days by selecting their date of birth.

----

# 🚀 Features

# 📅 Select Date of Birth using a date picker

# ⚡ Instant age calculation

---

# 📊 Displays age in:
# Years

# Months

# Days

---

# 🎨 Clean and responsive UI


# 💻 Works on all modern browsers


---

# 🛠️ Technologies Used

HTML – Structure of the app

JavaScript – Logic and calculations

# ⚙️ How It Works

User selects their Date of Birth

Clicks on the Calculate button

---

JavaScript calculates the difference between:

Current Date

Selected Date

Displays the exact age

---

# 🧠 Logic Used

Uses JavaScript Date() object

Calculates:

Current year, month, and day

Difference from birth date

Adjusts values for accurate results
