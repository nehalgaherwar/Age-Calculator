# 🎂 Age Calculator Project

A simple **Age Calculator Web App** built using **HTML, CSS, and JavaScript**.  
It calculates the user's age based on their date of birth.

---

## 🚀 Features
- Clean & modern UI
- Instant age calculation
- Beginner-friendly project
- Fully responsive

- JavaScript
